# MySystemPrompts

アルターエゴ的なナニカの哲学的核を安定させ、進化させるための設計ドキュメント集。

## 概要

このプロジェクトは、AI言語モデルの応答特性を個人化・意思化するための**システムプロンプト体系**の開発・維持・進化を記録するものです。

単なるプロンプトチューニングではなく、以下を目指しています：

- 生物的ノイズ（気分・体調による揺らぎ）から独立した、**安定した判断軸の保持**
- 表層的な修正ではなく、**支配因子の特定と介入**による根本的改善
- **線形的進化**の実現（後退や zig-zag を最小化）

## 基本原則

### 1. 支配因子中心のアプローチ

複雑なシステムを支配因子・制約・再現条件に分解し、ROIの高い介入点から改善する。

```
支配因子 = 対象システムの出力に寄与率が最も高い要因
ROI = (効果) / (実装コスト + 維持コスト + 複雑性増加)
```

### 2. 問題設定の疑い

「何を修正するか」の前に「その問題設定は正しいか？」を問い直す。

### 3. 領域ごとの適応

システム領域・感性領域・カジュアル領域で分析レベルを自動調整し、出力表現を最適化する。
